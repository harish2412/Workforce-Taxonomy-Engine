# Workforce Taxonomy Engine

Capstone project, Taxonomy of Work, Skill Taxonomy track.
Building a skill taxonomy from job postings, validated against ESCO.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

Copy `.env.example` to `.env` and fill in whichever API keys you use.

## Data

- `data/raw/sample_postings.csv` — 400 job development sample, 19 job families
- `data/extracted/skill_statements_sample.csv` — 13,958 extracted skill statements,
  with a `confidence` column (high / medium / low). Use high and medium only for
  Sprint 3 embedding and clustering.
- `data/esco/skills_en.csv` — ESCO reference skill list (~13,960 skills)
- `data/esco/skillsHierarchy_en.csv` — ESCO's own multi-level hierarchy, for
  Sprint 4 evaluation
- `data/golden_set/golden_dataset.xlsx` — 100 human-reviewed job postings with
  verified skill lists, the ground truth for precision/recall evaluation
- `data/golden_set/rule_nlp_extraction.xlsx` — Rule+NLP output on those same
  100 postings, for comparison against the golden set

## Pipeline (src/)

| Script | Sprint | Status |
|---|---|---|
| `clean_statements.py` | 3 | filters to high/medium confidence, dedupes |
| `embed.py` | 3 | embeds unique statements with sentence-transformers |
| `cluster.py` | 3 | k-means clustering, compares settings |
| `stability.py` | 3 | multi-seed stability check (Adjusted Rand Index) |
| `visualize.py` | 3 | UMAP projection, labeled cluster plot |
| `cluster_validation.py` | 4 (optional) | ESCO-category validation of cluster quality, needs manual labeling |

Run in order, each step reads the previous step's output from `data/processed/`.

## Embedding model

Currently `Qwen/Qwen3-Embedding-8B`, run on an Explorer GPU node (A100 or H200,
32GB+ memory). Earlier results used `all-MiniLM-L6-v2` on CPU. If you switch
models, update `MODEL_NAME` in both `src/embed.py` and `app.py`, the demo
loads embeddings generated by whichever model `embed.py` last used.

## Live demo

```powershell
streamlit run app.py
```

Type any skill phrase, see which cluster it's assigned to and what else is in
that cluster. Reads directly from `data/processed/`, run the pipeline first.
